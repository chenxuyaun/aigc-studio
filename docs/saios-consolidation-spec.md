# saiOS 收敛改造规格 ——「创作 AI 助手」定位

> 依据：用户"功能太多找不到/太乱/平凡没亮点"，并把改造决定权交给鲸鱼。
> 决策：定位 = **A · 创作 AI 助手**（一句话驱动创作，深层功能收敛，18 项导航 → 主次分明的 3+ 项）。

## 一、定位一句话
**saiOS 是「能跟你聊着创作的 AI 助手」**——你告诉它想做什么，它帮你做；你的作品都在这儿。

## 二、当前问题（实测审计）
- 侧栏导航 **18 项**平铺：创作/AI助手/数据看板/我的创作/提示词库/知识库/素材库/ASMR库/Agent库/角色扮演/任务中心/模型配置/用户管理/运行日志/上游状态…
- **没有主次、没有记忆点** → 平凡、找不到

## 三、收敛方案（目标结构）

### 主导航：18 → 精简为 3（+1 设置抽屉）
| 新导航 | 原入口 | 说明 |
|---|---|---|
| **AI 助手**（首页/对话） | AI 助手 | 主入口，一句话创作 |
| **我的作品** | 我的创作/作品 | 作品沉淀区 |
| **工具**（抽屉） | 提示词库/知识库/素材库/ASMR/Agent/角色扮演 | 创作工具收进能力中心/分组 |
| **设置**（右上抽屉，非导航） | 任务中心/模型配置/用户管理/运行日志/上游状态 | 系统管理收敛，须管理员 |

### 主导航应精简到的 label 数：3 个（AI助手 / 作品 / 工具）+ 1 个设置按钮

## 四、首页重点
- 无对话时 = AI 助手欢迎态（能力卡 + 最近作品预览），不再裸露 18 项
- "AI 助手"承担"一句话创作"记忆点

## 五、待办执行（分步，每步验证）
1. **P-A1**：AppShell 导航精简——把 18 项按上表分组，默认只显示 3 个主入口，系统管理收"设置"抽屉（管理员可见）
2. **P-A2**：工具类收进 AI 助手"能力中心/工具"分组，从默认视图隐藏但可打开
3. **P-A3**：验证全部原入口仍可访问（收进抽屉不删功能，只是不霸屏），tsc+build+部署
4. 之后可加：首页最近作品预览

## 原则
- **收敛 ≠ 删功能**：收进抽屉/设置，需要时可达
- **突出记忆点**：让"一句话创作"成为 saiOS 的唯一特点
- 每一步 npm build + 服务器部署验证，不留下半成品
