# saiOS「AI 助手」完善规格（源自 ZCode 文档研究）

> 依据：`D:\software\docs\study\zcode\` 下 20 篇 ZCode 产品文档，经 3 个并行子代理提炼（对话交互 22 条 / 多模态能力 18 条 / 安全自动化 16 条）。
> 用途：把 saiOS 首页对话中枢从"简单气泡列表"升级为"命令驱动、多模态、可控制、被记住"的 AI 助手。
> 技术栈：`apps/web/src/pages/AssistantHomePage.tsx` + `useChatSessions.ts` + 后端 `agent_chat.py` + MCP 工具（generate_image/comic/text、synthesize_speech、story_forge）。

## 设计总原则
能力不堆成导航菜单，而由「对话」驱动、并在对话里被看见。核心是 ZCode 的：
1. **先看清 AI 要做什么再放行**的控制感（执行模式 + 分级授权 + 待确认保留）
2. **长任务不丢状态**的确定性（运行历史 / 会话分组归档 / 自动继续）
3. **命令驱动的输入区**（`@`引用 / `#`会话 / `/`命令 / `$`技能）

## 落地顺序建议（按价值/成本）
1. **P0 现在就做**：欢迎态能力卡 + 媒体消息卡升级 + 工具透明条 + 再生成/下载（低改动，感知强）
2. P1：斜杠命令面板 + 编辑历史（输入体验质变）
3. P2：过程卡 + 画廓 + 记忆 + 分组（长任务友好）
4. P3：目标模式 / 安全确认 / 自动化（需后端扩展）

> ⚠️ 记忆可视化（特性 9/12）需确认 MemoryCore 后端暴露的注入内容；特性 15-18 需后端扩展确认通道，本期不先做。
