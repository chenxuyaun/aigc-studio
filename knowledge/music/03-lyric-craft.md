# 写词真经与写曲真经（音频应用·作词作曲方法论）

> 来源：audioapp.cn 论坛《看完这个保证你学会写歌》
> 类别：创作技法 · 词曲方法

## 写词真经（作词方法论）

### 1. 建立主题思想
- 先想清楚写什么：友情/爱情/亲情/某个故事背景；写人/写故事/写自己
- 主题先行，再动笔

### 2. 根据主题开脑洞（意象经营）
- 根据主题找意象展开联想：如写青春 → 秋千/教室/粉笔
- 练习法：找你喜欢的歌词逐句分析，提取意象，建立自己的意象库
- 写下与主题相关的词组、意象、画面短语（先不纠结韵脚），由一个想法延伸到另一个
- 方文山式意象（意象即画面）：
  - "异域" = 牙买加的雷鬼 / 北欧重金属 / 形而上的殖民地
  - "食物" = 摩卡咖啡 / 加了草莓的心形蛋糕
  - "爱恨痴情" = 空门 / 雨纷纷 / 草木深 / 孤城 / 野村
- 核心：意象要具体可感，让人"看见"，不是抽象名词

### 3. 押韵设计
- 尽量每句结尾押韵；积累自己的韵脚库（方文山、林夕都有韵脚库）
- 高音结尾用开口音（如 a/ang/an），低音结尾开口闭口音都可以
- 韵脚是习惯积累，不是临时凑

### 4. 内容逻辑
- 注意歌词内容的逻辑连接，切忌辞藻堆砌
- 不要动不动就"七弦琴/江山美人/似水流年"这类陈词滥调
- 辞藻服务于内容和逻辑，不是堆出来就高级

### 5. 灵感来源
- 多看电影、小说、散文、哲学、诗歌（读书：方文山《素颜韵脚诗》、《蕙风词话》、《人间词话》、《诗的八堂课》、《诗经》赋比兴、唐诗宋词）
- 多旅游、多经历情绪、研究林夕/黄伟文/方文山/林若宁/李宗盛/罗大佑/高晓松的作词
- 阅读和阅历是词库的来源

## 写曲真经（作曲方法论）

### 1. 明确主题目标
- 明确这首歌表达什么（先词后曲按词写；先曲后词按故事/情感写）
- 确定歌曲类型：流行情歌/动漫角色歌；写给朋友/爱人/同学；开心还是悲伤
- 确定曲风：电子/流行/中国风/爵士/Blues

### 2. 找灵感动机
- **按风格选音阶**（音阶决定情绪底色）：
  - 开朗风格 → 大调式；悲伤忧郁 → 小调式
  - 中国风 → 五声（宫商角徵羽 12356），可加变徵（#4）/清角（4）/变宫（7）/闰（b7）
  - 日本风 → 都节调式 34671
  - 异域风情 → 中古调式 Dorian（如霍尊《卷珠帘》用 Dorian）
- 听类似风格的音乐找感觉
- **先写和声框架，再写旋律**：套路进行（6415/4536251）有套路感，可以写让人眼前一亮的和弦进行
- 分解和弦可作动机：Am 和弦 613，变化顺序 316/136 即成旋律片段

### 3. 动机发展
- 把音符动机深入发展（重复/变化/对比），形成完整旋律
- 先完成歌曲结构和编曲，再打磨细节

### 6. 拟人必须可感（防抽象赋义）
- 拟人要有画面：草弯腰/叶刮脚踝/风把信纸吹到门槛——看得见摸得着
- 禁止概念化拟人："草认得她的脚""山记得那年"——把情感抽象成"认得/记得"是作者赋义，不是画面
- 判断标准：把拟人动词换成"感觉/知道"，句子还剩不剩画面？剩=好；不剩=抽象
