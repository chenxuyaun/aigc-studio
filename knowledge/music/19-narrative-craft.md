# 歌词叙事学（故事弧线、人物、场景的歌词化）

> 类别：创作技法 · 叙事（把"讲故事"变成歌词技术）

## 一、叙事弧线（Arc）在歌词里的落地

完整弧线：**陌生 → 好奇 → 真相 → 理解 → 心碎/释然**

歌曲段落对应：
- 主歌1：立场景、立人物（不揭底）——听众"你是谁？"
- 预副歌：情绪抬升，抛出疑问
- 副歌：Hook 亮相（只露一半，设悬念）
- 主歌2：给转折/真相（"那年梅雨天，胥江翻船"）
- 副歌2：Hook 递进（补全真相）
- 桥段：点破/主题句（"我渡的是桥没修好之前的人"）
- 最终副歌：完整 Hook + 情绪峰值

## 二、人物（歌词里的"立人"）

人物 = 身份 + 一件具体的事 + 一个代价：
- 身份："修理工老周""卖白兰花的人"
- 具体的事："把旧伞倒挂在石栏上让没伞的人自己取"
- 代价："女儿那年没回来，他申请调来扫这段路"

**自检三问**：
1. 删掉创伤，人物还成立吗？（人物不能只是"创伤的容器"）
2. 没有妻子/女儿，他还会这么做吗？（行为要能反推人物价值）
3. 行为是"他果然会这么做"还是"作者为了让我哭"？

## 三、场景（一段只写一个场景）

- 一段歌词 = 一个场景 = 一个动作 + 一个感官 + 一个细节
- 场景要"立得住"：谁在哪儿、做什么、闻到/摸到/听到什么
- 时间感：一个物件压着"从哪年到哪年"（"从她十二岁纳到二十三岁"）
- 禁止时间线流水账（清晨…午后…深夜…= 汇报，不是叙事）

## 四、情绪（克制地传递）

- **用物件代替形容词**：不说"他很孤独"，写"电话亭的听筒积了灰"
- **用动作代替心情**：不说"她很难过"，写"她把粥凉了又热，热了又凉"
- **留白**：重要的不说破，让听众自己接（"他没说话，把灯调亮了一档"）
- **一次心口之言**：全曲允许 1-2 句人物直接说出心里话，其余用细节

## 五、钩子与叙事的关系

- 叙事歌的 Hook 是"人物的一个动作/一句话"，不是格言
- Hook 里的人和事，主歌必须先铺垫（副歌不能凭空引入新人物）
- 三遍递进：第一遍设悬念 → 第二遍揭真相 → 第三遍只剩词根

## 六、代价与重量

- 好叙事歌有"不可逆的失去"：报名表锁进铁皮柜 / 女儿去了东莞流水线
- 失去要具体：不是"失去了青春"，是"那封没寄出的信还压在箱底"
- 时间跨度：一个意象压着年月（"扫了十九年"比"扫了很久"重一万倍）

## 七、叙事歌的禁忌

- 不要"先给结果再解释原因"（除非 Hook 设计需要）
- 不要用旁白代替人物（"老人望着远方，眼里满是沧桑"= 观察报告）
- 不要主题先行（"写一个歌颂奉献的人"→ 人物成了传声筒）
- 不要强行升华（平凡→哲理→永恒；没有代价就没有意义）
