# 旋律创作方法论（动机、发展、乐句设计）

> 类别：创作技法 · 旋律（之前知识库偏重作词，补旋律短板）

## 一、动机（Melodic Motif）：旋律的最小种子

- 动机 = 2-4 个音的小片段，是旋律的 DNA（如《贝多芬第五》的四音动机）
- 从歌词第一句的音调来（说话的自然语调=旋律雏形）
- 从分解和弦来（Am 的 613 变化顺序 316/136 即成片段）
- 从风格音阶来（五声/多利亚的特定音程组合）

## 二、动机发展（Motif Development）：让种子长大

五种基本发展法：
1. **重复**：原样重复（记忆）——但连续重复不超过 3 次
2. **变化重复**：改结尾（变尾）——同头不同尾，最常用
3. **模进（Sequence）**：整体上移/下移一个音程（二度/三度）
4. **倒影/逆行**：音程方向反转（上行变下行）
5. **节奏变化**：同样音高，节奏拉长/压缩（时值扩张/紧缩）

一段旋律 = 动机 + 发展，而不是"一句一个新旋律"（那是拼凑不是写作）

## 三、乐句结构（Phrasing）：旋律的"呼吸"

- **问答结构**：前句"问"（上行动机/开放感），后句"答"（落音/闭合感）
- **乐句长度**：8 小节为标准单位（4+4 问答）；歌词一句对应 4-8 拍
- **落音设计**：乐句尾音是情绪点——落主音（稳定）/落三音（温暖）/落五音（期待）
- **高点设计**：每段旋律有一个最高音（情绪峰值），放在副歌 Hook 上

## 四、旋律与歌词的配合

- **音调从词来**：旋律走向跟着歌词的自然语调（疑问句上扬、陈述句下落）
- **长短相配**：长音给关键词/长词，短音给虚词/助词
- **开口音上高音**：歌词高音处用开口音（a/ang），好唱且亮
- **断句即气口**：旋律的休止 = 歌词的断句点，一起呼吸

## 五、旋律的"记忆点"设计

- **Hook 旋律**：音程跳跃大（跳进）+ 节奏独特 + 音高最高 = 最容易记住
- **重复小段**：副歌旋律重复 2-3 遍（同头变尾），强化记忆
- **音域控制**：主歌低（叙述）、副歌高（情绪），全曲音域 1-1.5 个八度（可唱性）
- **避免**：全曲无变化平推（催眠）；每句都是新旋律（记不住）；音域过宽（难唱）

## 六、旋律的情绪色彩

- 上行 = 希望/紧张/上扬；下行 = 落定/伤感/释放
- 大调旋律 = 明亮；小调旋律 = 暗淡；多利亚 = 苍凉独特
- 级进（相邻音）= 平缓叙事；跳进（三度以上）= 情绪起伏/戏剧
- 半音 = 细腻痛苦；全音 = 舒展
- 长音停留 = 深情/执念；急促音 = 焦虑/兴奋

## 七、旋律创作流程（可操作）

1. 定情绪 → 选音阶/调式
2. 从歌词首句音调孵化动机
3. 用"重复+变化尾"发展出主歌旋律
4. 副歌旋律用"跳进+高点"做 Hook（歌词 Hook 同一句）
5. 检查：能哼吗？唱得动吗？最高点在最该爆发的地方吗？
